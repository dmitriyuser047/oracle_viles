# Велес

Велес — персональный AI-оракул для символического анализа жизни, отношений, снов и переписок. Он соединяет оракульный стиль, психологическую внимательность и эзотерические модели так, чтобы пользователь получал не сухую справку, а цельный разбор ситуации: что происходит, где скрыто напряжение, какой ресурс уже есть и какой шаг сделать дальше.

## Что умеет Велес

- **Оракул** — отвечает на жизненные вопросы через личный профиль, дневник событий и скрытые символические опоры.
- **Таро** — делает расклады на колоде Райдера-Уэйта, включая старшие и младшие арканы.
- **Сонник** — разбирает сны как сюжет подсознания: тип сна, главный образ, скрытое чувство и практический шаг.
- **Переписки** — анализирует сообщения, помогает понять тон общения и подобрать варианты ответа.
- **Энергии диалога** — показывает, какие чакры и энергетические перекосы проявились в контакте.
- **Связи** — рассчитывает и разбирает связь между двумя людьми по датам рождения, стихиям, числам и матрице пары.
- **Профиль** — собирает личную карту: знак, стихию, нумерологию, таро, руны, чакры, тотем и матрицу.
- **Дневник** — сохраняет события, помогает видеть повторяющиеся паттерны и возвращаться к старым записям.

## Принцип ответа

Велес не должен звучать как справочник или набор ссылок. Внутренние модели используются под капотом, а ответ остаётся живым, связным и понятным. Он не выдаёт фатальных приговоров, не ставит диагнозы и не заменяет выбор пользователя готовой догмой.

Главный стиль Велеса: увидеть узор, назвать напряжение, вернуть человеку силу и дать конкретное действие.

## Релиз v1.0.0

Первый цельный релиз собрал основные режимы приложения:

- отдельные чаты для оракула, таро, переписок, энергий диалога и сонника;
- расширенную базу сонника с типами снов и практиками после сна;
- рабочий раздел связей с расчётом пары и AI-разбором;
- чистку ответов от ссылок, источников и лишних объяснений систем;
- более аккуратную грамматику и обращение к пользователю на "ты";
- защиту от слишком больших запросов к AI за счёт сокращения длинных сообщений и старых записей дневника.

## Локальный запуск

```bash
npm install
npm start
```

По умолчанию приложение открывается на:

```text
http://localhost:3000
```

Для работы AI нужен ключ провайдера в `.env`. По умолчанию можно использовать Claude, а Groq оставить запасным:

```text
AI_PROVIDER=anthropic
ANTHROPIC_API_KEY=your_claude_key_here
ANTHROPIC_MODEL=claude-haiku-4-5
GROQ_API_KEY=your_groq_key_here
```
